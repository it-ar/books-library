# مكتبة الكتب — صفحة البحث والعرض

صفحة ويب لعرض كتب المكتبة والبحث فيها وتصفّحها حسب التصنيف. البيانات مُستخرجة
من ملف إكسل المكتبة.

## المزايا

- **بحث فوري** في اسم الكتاب واسم المؤلف مع تظليل الكلمات المطابقة.
- **بحث عربي ذكي** يتجاهل التشكيل ويوحّد الحروف (أ/إ/آ ← ا، ة ← ه، ى ← ي)
  فتظهر النتائج حتى مع اختلاف الكتابة.
- **تصفية حسب التصنيف** عبر شرائح تعرض عدد الكتب في كل تصنيف.
- **ترتيب** حسب الاسم أو المؤلف أو عدد النسخ أو التصنيف.
- **بطاقة تفاصيل** لكل كتاب (التصنيف، المؤلف، عدد النسخ، رقم الصندوق، السنة/النوع).
- تصميم متجاوب (جوال/حاسب)، يدعم الوضعين الفاتح والداكن، ويعمل دون اتصال إنترنت.
- عرض تدريجي (Lazy load) يتحمّل آلاف الكتب بسلاسة.

## البنية

```
books-library/
├── index.html              الصفحة الرئيسية
├── assets/
│   ├── styles.css          التنسيقات
│   ├── app.js              منطق البحث والعرض
│   └── books-data.js       البيانات (مُولّدة) — يقرأها الموقع مباشرة
├── data/
│   └── books.json          نفس البيانات بصيغة JSON
└── tools/
    └── convert_excel.py    أداة تحويل الإكسل إلى بيانات
```

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

يمكن نشر المجلد كما هو على أي استضافة ثابتة (GitHub Pages مثلًا).

## تحديث البيانات من إكسل جديد

عند تعديل ملف الإكسل، أعد توليد البيانات:

```bash
pip install openpyxl          # مرة واحدة
python3 tools/convert_excel.py "مسار/ملف-المكتبة.xlsx"
```

يُنشئ الأمر `data/books.json` و`assets/books-data.js` تلقائيًا.

### بنية الإكسل المتوقعة

- كل ورقة (Sheet) تمثّل تصنيفًا، واسم الورقة يصبح اسم التصنيف.
- الأعمدة المعتادة: **اسم الكتاب | المؤلف | عدد النسخ | رقم الصندوق**.
- ورقة **«اصدارات الهيئة»** تُعالَج بأعمدتها الخاصة (النوع | الاسم | سنة الإصدار | العدد | الصندوق).
- ورقة **«المكتبة شاملة…»** يجري تجاهلها لأنها تجميع مكرّر للتصنيفات.

الأداة تتجاهل صفوف العناوين والأقسام تلقائيًا. عدّل قوائم التخطي في أعلى
`tools/convert_excel.py` إن تغيّرت أسماء الأعمدة أو الأوراق.

القانون، التاريخ، عام، اللغة والأدب والفنون، السياسة، غير اللغة العربية،
